## 3. 보안 감사 (PHASE 6)
### A. XSS — 위험 경로 없음(확인)
- 사용자 입력은 펫 이름·친구 코드 이름·백업 코드뿐. 이름은 입력 때 `cleanName`(648행)이 `<`·`>`·제어문자·방향 제어 문자를 지우고 8자로 자른다.
- 이름이 화면에 나오는 곳 23곳 중 HTML 템플릿에 들어가는 9곳은 `escapeHTML`(643행) 적용. 나머지 14곳은 `say()`·`toast()`(둘 다 `textContent`), 대화창 `typeText`/버튼(`textContent`), 캔버스 `fillText` 경로라 HTML로 해석되지 않는다.
- `innerHTML` 106곳은 대부분 게임 내장 데이터(친구·아이템 이름)만 넣는다.
- 개선(P2): `cleanName`이 따옴표는 지우지 않는다 — 속성에 들어갈 때 `escapeHTML`이 막지만, 방어를 겹치려면 따옴표도 제거. 악성 문자열(이벤트 핸들러·따옴표) 시험 추가.
### B. CSP
- `script-src 'self' 'unsafe-inline'` — 게임 전체가 인라인 스크립트 1개라 필요. 인라인 이벤트 속성(onclick 등)은 0곳.
- 해시 기반(`'sha256-…'`) 전환은 기술적으로 가능하지만, **Capacitor 앱이 페이지에 브리지 스크립트를 넣는 방식과 충돌할 수 있어** 실기기 확인 없이 바꾸면 앱이 깨질 위험. → P2(웹판 먼저 시험, 앱은 기기 확인 후).
### C. 보호자 인증 — 양호
- PIN: PBKDF2-SHA256 15만 회 + 무작위 소금(`pinHash` 4926행), 원문 저장 없음.
- 복구 코드: `crypto.getRandomValues` 8자, 해시로만 저장, 만들 때 한 번만 표시. 틀리면 5회부터 1분→최대 1시간 잠금(4998행).
- 한계(문서에 명시돼 있음): PIN이 없으면 곱셈 문제로 통과 — 성인 인증 아님. 기기 데이터 삭제로 PIN이 사라지는 것은 막을 수 없음.
### D. 저장 데이터 — 양호, 1건 보완
- `saveGuard`(1005행) 허용 목록·범위 검사, 깨진 저장은 `-invalid`로 보관(1171행), 복원 전 `-before-restore`로 원본 보존(5127행), 시험 다수.
- **P1: `persist()`(1180행)가 저장 실패(저장 공간 부족·사생활 보호 모드)를 조용히 무시** → 아이·보호자가 진행이 저장 안 되는 것을 모름. **[현재 상태: `8a03d25`에서 저장 실패·회복 안내 구현]**
- **P1(웹판): `navigator.storage.persist()` 미사용** → 브라우저가 저장 공간이 부족할 때 기록을 지울 수 있다(앱판은 해당 적음). **[현재 상태: `8a03d25`에서 웹판만 요청하도록 구현]**
### E. 어린이 개인정보 — 양호
- 외부 전송 코드 없음(fetch·XHR·WebSocket·sendBeacon 사용 0곳, CSP `connect-src 'self' blob:`). 위치·카메라·마이크 사용 0곳. `console.log` 0곳.
- 저장 위치: 기기 localStorage만. 사진 기능은 게임 화면 캡처(사람 사진 아님).
- **출시 전 필수: 개인정보처리방침의 문의 이메일이 자리표시**(`www/privacy.html` 49·76행).
### F. 배포 보안
- 외부 CDN 없음(three.js r128·GLTFLoader는 `www/vendor`에 포함, 라이선스 동봉). 서비스 워커는 버전 문자열로 캐시 교체.
- GitHub Actions 비밀값은 `secrets.*`로만 사용, 로그 출력 없음. 서명 키는 사용자 PC에서 만들고 비밀값으로 등록(`tools/make_upload_key.cmd`).
- Android 권한: Capacitor 기본(INTERNET) + TTS 조회(queries)만.

## 4. 캐릭터·애니메이션·3D (PHASE 2·5)
- 사람 주인공 없음, NPC 8명 모두 동물(`FRIENDS` 4015행). 사람 캐릭터는 **실제 GLB 모델(뼈대·애니메이션 포함)** 이 있어야 하며, 지금 펫 빌더(`buildPet`)나 곰 GLB를 사람에 재사용하지 않는다. **[현재 상태: 사람 주인공 구현됨, NPC는 여전히 동물]**
- 곰 GLB 애니메이션 10개는 게임에서 재생되지 않음(위 2장). 사람 모델 도입 시 `AnimationMixer` 기반 재생·전환을 함께 만든다. **[현재 상태: 재생됨(`8a03d25`)]**
- 3D 부하: 광장 메시 40개·곰 1만 800 삼각형, 저사양 재질 분기(`LOW_GFX` 1651행). **실기기 FPS·메모리 미측정.**
- 모델 후보(라이선스 확인됨): Kenney *Mini Characters*(CC0, 귀여운 비율, 애니메이션 포함 — 파일 구성은 내려받아 확인 필요), Quaternius *Universal Base Characters + Animation Library*(CC0, 사실적 비율).

## 5. 재미·첫 경험·영어 연결 (PHASE 3·4)
- 첫 3분: 펫 고르기 → 알 부화 → 집 → 첫 모험 카드까지 바로 보인다(스토어 스크린샷 1에서 확인). 첫 보상(첫 모험)은 마을까지 나가야 시작.
- 반복 동기: 미션·배지·별 조각 1/5. 새 사건·새 지역 해금은 아직 적다.
- 영어 연결: 첫 모험은 대사·단어가 진행에 붙어 있으나, 대부분의 영어는 레슨·영어 게임 메뉴 안에 있다.

### P1 — 중요 (다음 단계, 코드로 가능)
1. `persist()` 저장 실패 안내 + 연속 실패 시 백업 코드 안내

4. 사람 주인공 + 펫 동반 설계·에셋 검증(사용자 결정 완료: 사람 주인공 + 펫 동반, CC0 모델)

### P2 — 개선 권장
1. `cleanName`에서 따옴표도 제거 + 악성 입력 시험 추가
2. CSP 해시 기반 전환(웹판 시험 → 기기 확인 후 앱)
3. 실기기 성능 시험 계획(저사양·일반 Android, iPhone, 세로·가로, 오프라인, 장시간)과 측정 표시
4. `dispose()`가 적은 곳(펫 교체·미니게임 반복) 메모리 측정
