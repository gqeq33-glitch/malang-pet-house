# 3단계: 영어 내용 품질 검사와 검수

> **상태: 영어 교사·원어민 검수 전. "검증 완료"가 아닙니다.**

## 기계로 검사한 것 (`tests/content.test.js`)

레슨별 카테고리·권장 나이·학습 목표, 알파벳 첫 글자, a/an, 대문자 I, 띄어쓰기, 영국식 표기, 같은 단어 반복, 한 레슨 안에서 뜻이 겹치는 단어도 검사합니다. 레슨 번호 중복, 단어·문장 형식과 뜻 누락, 같은 단어의 뜻 불일치, 한 레슨 안 그림 중복, 정답과 오답의 중복, 빈칸 표시 누락, 회화 개수와 중복, 문장의 대문자와 문장 부호, 단계별 문장 길이, 학습 영역 누락.

## 자체 검토에서 고친 것 (2026-11-06)

교사나 원어민 검수가 아니라 제작 과정의 자체 검토입니다.

- X의 정답이 box인 "이 글자로 시작하는 그림" 문제: box는 X로 시작하지 않으므로 "들어 있는 그림"으로 바꾸고, 첫소리 문제에서 뺐습니다.
- `X is in box`를 `X, as in box`로 수정
- `scared`의 뜻을 "무서운"에서 "무서워하는"으로 수정
- `jump`의 캥거루 그림 제거
- "고래는 가장 큰 동물"을 사실에 맞게 `The blue whale`로 수정
- `Sorry I am late.`를 더 자연스러운 `Sorry I'm late.`로 수정
- 저학년 문장이 고학년보다 길어지지 않게 짧게 수정

## 검수자가 특히 봐 주면 좋은 그림

그림 문자로 뜻을 정확히 나타내기 어려운 단어입니다: `goodbye`(🙋), `sorry`(😢), `hungry`(🤤), `cup`(🥤), `ball`(⚽), `eat`(🍽️), `sing`(🎤). `window`(🪟), `yo-yo`(🪀), `toothbrush` 그림(🪥) 같은 새 그림 문자는 오래된 기기에서 네모로 보일 수 있습니다.

## 기계로 확인할 수 없는 것

- **번역의 자연스러움과 정확성**
- **실제 발음:** 기기 TTS를 쓰므로 기기마다 다릅니다. 게임은 화면 글자와 같은 문장을 읽도록 확인했지만, 소리 자체는 듣지 못했습니다.
- **파닉스:** TTS로는 낱소리(/b/ 같은)를 정확히 낼 수 없어, 같은 소리가 나는 단어로 익히는 방식입니다. 낱소리 교육에는 녹음 음성이 필요합니다.
- **연령 적합성과 교육과정 대응:** 제작자가 구성한 것이며 초등 영어 교육과정과 하나하나 대조하지 않았습니다.
- **오답 보기의 교육적 타당성**

## 검수 방법

레슨, 문장 기차, 이야기 극장, 이야기 모험의 문장이 모두 들어 있어요. 펫 카페의 주문 문장과 정글의 길 안내는 프로그램이 만들어 CSV에 없으니 게임에서 함께 확인해 주세요. `docs/content_review.csv`를 스프레드시트로 열어 `검수 결과`와 `수정 제안` 칸을 채웁니다. 다시 만들려면:

```bash
python tools/export_content.py
```

## 검수 체크리스트

- [ ] 영어가 어린이에게 자연스러운 표현인가
- [ ] 한국어 뜻이 맞고 쉬운가
- [ ] 정답이 하나뿐인가 (오답 보기도 말이 되는 경우는 없는가)
- [ ] 단계와 나이에 맞는가
- [ ] 미국식·영국식 표기가 섞이지 않았는가
- [ ] 문화적으로 부적절한 내용이 없는가
- [ ] 기기 음성으로 들었을 때 발음이 틀리지 않는가

검수를 마치기 전에는 게임 안에 "영어 교사나 원어민의 검수를 받지 않았어요"라는 보호자 안내를 유지합니다.
