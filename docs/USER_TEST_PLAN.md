# 5단계: 보호자 동의 소규모 사용자 시험 계획

> **상태: 계획과 양식만 준비됨. 실제 시험은 아직 하지 않았고 이용자 데이터는 0건입니다.**
> 가장 많이 쓰는 기능, 이탈 원인, 출시 가능 여부는 시험 후에만 판단할 수 있습니다.

## 1. 대상과 기간

| 그룹 | 인원(권장) | 비고 |
|---|---|---|
| 초등 저학년(1~3학년) | 5~8명 | 보호자와 함께 |
| 초등 고학년(4~6학년) | 5~8명 | 보호자 동의 후 |
| 보호자 | 참여 아동의 보호자 전원 | 설문 |

기간은 7~10일입니다. 하루 사용 시간은 보호자가 정하고, 매일 하라고 요구하지 않습니다. 현금성 보상은 주지 않습니다. 이 인원은 경향을 보는 탐색 시험이며 통계적으로 일반화할 수 없습니다.

## 2. 진행 순서

1. 보호자에게 안내문을 전달하고 서면 또는 전자 동의를 받습니다.
2. 참여 코드(예: `T01`)를 나눠 주고, 이름과 코드의 연결표는 만들지 않거나 운영자만 따로 보관한 뒤 시험 후 폐기합니다.
3. 첫날: 보호자 옆에서 아이가 설명 없이 시작합니다. 진행자는 도와주지 않고 막힌 곳만 기록합니다.
4. 7일 후: 보호자가 **보호자 메뉴 → 시험 참여 기록 → 기록 복사**를 눌러 전달하고 설문을 작성합니다.
5. 결과 정리 후 참여 코드 기록을 폐기합니다.

## 3. 측정 지표

| # | 지표 | 얻는 방법 | 계산 |
|---|---|---|---|
| 1 | 튜토리얼 완료율 | `tutorialDone` | 완료 인원 / 참여 인원 |
| 2 | 첫 플레이 시간 | `tutorialSec`, 관찰 | 중앙값 (목표 3~5분) |
| 3 | 다음 날 재방문율 | `visitDays`에 1 포함 | 해당 인원 / 참여 인원 |
| 4 | 7일 후 재방문율 | `visitDays`에 7 포함 | 해당 인원 / 참여 인원 |
| 5 | 영어 미션 완료율 | `lessons`, `dailyDone`, `right`, `wrong` | 인원당 레슨 수, 정답률 |
| 6 | 꾸미기·성장 이용률 | `wearOwned`, `hatsOwned`, `decorPlaced`, `petLevels` | 1개 이상 이용 인원 비율 |
| 7 | 오류·데이터 손실 | `errors`, 보호자 설문, 관찰 | 건수 |
| 8 | 교육적 만족도 | 보호자 설문 | 5점 척도 평균과 의견 |
| 9 | 유료 구매 의향 | 보호자 설문 | 가격별 응답 (실제 구매와 다를 수 있음) |

재방문율은 아이에게 재방문을 재촉하지 않은 자연스러운 값을 재야 합니다. 알림이나 독촉 연락을 보내지 않습니다.

**기록 예시 (이름 없음)**

```json
{"app":"3.3","stage":1,"tutorialDone":true,"tutorialSec":240,"firstPlaySec":240,"visitDays":[0,1,3],"lessons":4,"right":60,"wrong":12,"dailyDone":1,"engLevel":5,"petLevels":[3],"wearOwned":1,"hatsOwned":2,"decorPlaced":1,"errors":0}
```

## 4. 수집하지 않는 것

어린이의 이름, 이메일, 위치, 사진, 음성, 학교, 연락처, 기기 ID는 수집하지 않습니다. 관찰할 때 녹화와 녹음을 하지 않고, 필요하면 보호자에게 별도로 동의를 받습니다. 게임의 펫 이름은 기록에 들어가지 않습니다.

## 5. 보호자 안내 및 동의서 양식

> 아래는 초안입니다. 만 14세 미만 아동의 개인정보를 다루므로 실제 사용 전 법률 전문가의 확인을 권합니다.

**말랑 영어 펫하우스 시험 참여 안내**

- **목적:** 게임이 아이에게 쉽고 재미있는지, 영어 학습에 도움이 된다고 느끼는지 알아보기 위한 출시 전 시험입니다.
- **하는 일:** 7~10일 동안 원하는 만큼 게임을 하고, 끝난 뒤 보호자가 진행 기록을 복사해 전달하고 설문에 답합니다.
- **받는 정보:** 이름 없는 게임 진행 숫자, 보호자 설문 응답, 보호자 연락처(안내용).
- **받지 않는 정보:** 아이의 이름, 사진, 음성, 위치, 학교.
- **보관:** 분석에만 사용하고, 결과는 개인을 알아볼 수 없게 합산합니다. 시험 종료 후 [기간] 안에 삭제합니다.
- **자발적 참여:** 언제든 그만둘 수 있고 불이익이 없습니다. 요청하시면 받은 자료를 삭제합니다.
- **주의:** 출시 전 버전이라 오류나 기록 손실이 있을 수 있습니다. 영어 내용은 아직 교사나 원어민의 검수를 받지 않았습니다.
- **책임자·문의:** [운영자 이름] / [실제 연락처]

## 6. 보호자 설문

1. 아이가 혼자 시작할 수 있었나요? (1~5)
2. 영어 공부에 도움이 된다고 느끼나요? (1~5) 그 이유는?
3. 아이 나이에 난이도가 맞았나요? (너무 쉬움 / 적당 / 너무 어려움)
4. 영어 발음이나 번역에서 이상한 곳이 있었나요? 어디인가요?
5. 아이가 어떤 기능을 가장 좋아했나요?
6. 그만두거나 지루해한 순간이 있었나요?
7. 오류, 멈춤, 기록 사라짐이 있었나요?
8. 사용 시간이 지나치다고 느꼈나요?
9. 안전 면에서 걱정되는 점이 있나요?
10. 프리미엄이 있다면 얼마까지 낼 의향이 있나요? (안 냄 / 월 3,900원 / 연 29,900원 / 콘텐츠 팩 4,900~9,900원) 무엇이 있어야 낼 건가요?

## 7. 결과 보고 양식

| 항목 | 작성 내용 |
|---|---|
| 참여 인원, 완주 인원 | 저학년 / 고학년 |
| 지표 1~9 결과 | 표 |
| 많이 쓰는 기능 | 실제 기록 기준 |
| 이탈 지점과 원인 | 관찰과 설문 기준 |
| 개선 우선순위 | 치명 오류 → 안전 → 학습 → 재미 |
| 출시 판단 | 아래 기준 |

**출시 전 권장 기준 (가설, 시험 전에 확정):** 데이터 손실 0건, 안전 문제 0건, 튜토리얼 완료율 80% 이상, 교육 만족도 평균 4점 이상, 치명적 오류 0건.
