### P2 — 개선 권장
1. 주인공을 받는 도중 교체하면 늦게 도착한 모델의 기하·텍스처를 해제하지 않는다.
2. "발음 별 수집" 이름이 평가처럼 보일 수 있다 → "따라 말하기 별"처럼 바꾸기.
3. 사람용 기쁨·슬픔·놀람·춤 동작이 없다 → 기존 동작 조합(`emote-yes` + 점프 등) 또는 다른 CC0 동작(라이선스 확인 후).
4. 첫 화면 정보량 줄이기(처음 몇 분은 미션 1개만 보이기 등). 아이 시험 후에 결정.
5. CSP 해시 전환, 친구 코드 입력 길이 상한, 장시간 메모리 측정.
