## 만든 방법과 라이선스

- 외부 AI 서비스(Firefly, Leonardo, Meshy, Tripo)나 남의 에셋을 쓰지 않았습니다. 이 프로젝트에서 three.js 코드로 직접 설계하고 GLB로 내보냈습니다.
- 그래서 출처 표시 의무나 사용료가 없고 프로젝트 소유입니다.
- 다시 만들기: `tools/assetmaker/`에서 `python save_server.py 저장폴더` 를 실행하고 브라우저로 `http://127.0.0.1:8808/` 을 열면 GLB와 그림(PNG)을 저장 폴더에 다시 만듭니다. 이 도구는 three.js r128과 내보내기 도구를 인터넷(CDN)에서 불러옵니다.
- 디자인 그림(PNG)은 `Documents\malang_world_assets\`에 있습니다(게임 저장소 밖).

## 게임 연결 방식

- 펫이 곰이고 설정의 "새 그래픽"이 켜져 있으면 `malang_bear.glb`로 펫을 만들고, 기존 걷기·점프·동작 코드가 GLB의 관절을 움직입니다. 표정은 눈·입 그림을 바꿔 보여 줍니다.
- 저장 데이터의 종족 이름(`bear`), 레벨, 모자, 옷, 염색은 그대로 쓰입니다.
- 모델을 못 불러오면(오래된 기기, 파일을 직접 여는 실행 등) 예전 곰과 예전 분수가 그대로 나옵니다.
- 보안 설정(CSP)의 `connect-src`에 `blob:`을 더했습니다. GLB 안의 그림을 기기 메모리에서 읽기 위한 것이고, 외부 서버 연결은 여전히 막혀 있습니다.

## 확인하지 못한 것

- 실제 저사양 휴대폰에서의 프레임은 재지 않았습니다. 저사양 기기(코어 4개 이하 또는 메모리 3GB 이하)는 코팅 광택 없는 가벼운 재질을 씁니다.
- 곰은 펫 하나만 가까이 보이므로 멀리용 모델(LOD)은 만들지 않았습니다. 필요하면 제작기에서 분할 수를 더 줄인 모델을 내보내면 됩니다.
