## 4. 사람 캐릭터 개편에 필요한 결정과 에셋

### 사용자 결정 필요
1. **주인공 구조**: ① 사람 주인공 추가 + 펫은 동반자(조작·저장·퀘스트 큰 변경, 마이그레이션 필요) ② 펫을 계속 조작하고 NPC만 사람으로(변경 작음)
2. **사람 3D 모델 출처**
   - (추천) **Quaternius 등 CC0 무료 캐릭터**(뼈대·걷기/뛰기 애니메이션 포함 GLB) — 상업 사용 가능, 출처 표시 의무 없음. 내려받기 전에 라이선스 페이지 재확인·승인 필요
   - 직접 제작(Blender 4.5 설치돼 있음) — 시간이 많이 들고 품질 보장 어려움
   - 유료 에셋 — 승인 필요
3. **게임 이름 "펫하우스"와의 관계**: 사람 중심이 되면 펫의 비중을 어떻게 둘지

### 실제 모델이 없는 동안 하지 않을 것
- 구·원기둥으로 만든 사람을 완성품이라고 내놓지 않는다.
- 모델이 없으면 기존 동물 캐릭터를 그대로 두고, 모델 로딩 실패 시에도 지금 캐릭터로 자연스럽게 대체한다.
